# Archived Build-Time & Session Documentation

This directory preserves historical planning specifications, point-in-time gap analyses, deprecation postmortems, and AI session handoff logs from the development of **Ogre Battle PC**.

These documents are kept for historical traceability only and are superseded by the shipped codebase, root documentation (`README.md`, `ROADMAP.md`, `CHANGELOG.md`), and `docs/architecture/`. A consolidated **Lessons Learned** retrospective is planned for a future pass.
